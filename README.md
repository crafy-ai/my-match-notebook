# 我的观赛手札

一个以北京时间整理世界杯与 CS2 科隆 Major 赛程的静态网页。

## 功能

- 按日期查看比赛时间、队伍、比分与比赛状态
- 世界杯小组积分榜与 CS2 瑞士轮实时态势
- 队徽、国旗与当前排名信息
- 只看未来、深夜场、正常时间和收藏筛选
- 根据个人偏好标记值得关注的比赛
- 世界杯与 CS2 赛事新闻滚播

## 本地预览

在项目目录运行：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

随后访问 `http://127.0.0.1:4173/`。

## 部署

推送到 GitHub 默认分支后，`部署 GitHub Pages` 工作流会自动发布网站。
